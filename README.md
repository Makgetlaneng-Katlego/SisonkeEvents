# SisonkeEvents 🎉

Welcome to **SisonkeEvents**! A simple and easy-to-use Android app for discovering, saving, and managing local events. 

## ✨ Features
* 🔍 **Discover Events**: Browse events happening around you.
* ❤️ **Save Favorites**: Keep a personal list of events you want to attend.
* ✈️ **Works Offline**: View your saved events even when you lose internet connection.
* 🔐 **Google Sign-In**: Fast and secure login using your Google account.

## 🛠️ Built With
* **Kotlin** - Main programming language.
* **Jetpack Compose** - For the modern user interface.
* **Retrofit** - For fetching event data from the internet.
* **SQLite** - For local/offline storage.
* **Google Sign-In** - For secure user authentication.

## 🚀 How to Run the App
1. Clone or download this repository.
2. Open the project in **Android Studio**.
3. Wait a moment for Gradle to finish syncing.
4. Click the green **Run** ▶️ button at the top to launch the app on an emulator or your physical phone.
